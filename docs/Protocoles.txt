OpenPort — Ports et protocoles
RustyPort

Lire les ports dans OpenPort

Un port désigne un point de communication sur une machine. Une entrée
OpenPort indique le numéro, le protocole, l’adresse locale et le processus
qui l’utilise. Le PID identifie le processus en cours d’exécution.

TCP établit une connexion et remet les données dans l’ordre. OpenPort
affiche les ports TCP en écoute et le nombre de connexions établies
associées au même PID, au même port et à l'adresse locale. Une écoute
générique inclut ses adresses de la même famille IP. Une connexion peut
rester établie sans échanger de données et les connexions très brèves
peuvent passer entre deux relevés.
Référence TCP (RFC 9293) — https://www.rfc-editor.org/rfc/rfc9293.html

UDP transmet des datagrammes. Ceux-ci peuvent arriver en désordre ou se
perdre. OpenPort affiche les sockets UDP liées à un port local. Certaines
servent à recevoir, d’autres à envoyer, et certaines font les deux.
Référence UDP (RFC 768) — https://www.rfc-editor.org/rfc/rfc768.html

L’adresse locale indique où le programme utilise le port.

  127.0.0.1 et ::1   Ce PC uniquement, via l’adresse de bouclage
  0.0.0.0            Toutes les adresses IPv4 locales
  ::                 Adresse générique IPv6
  192.168.x.x        Exemple d’adresse d’une interface du réseau local

L’accès depuis un autre appareil dépend aussi des règles de pare-feu et
de la configuration du réseau.
Adresses locales Windows — https://learn.microsoft.com/en-us/windows/win32/api/winsock/nf-winsock-bind

Ports courants

  Port et protocole    Usage habituel
  22/TCP               SSH, administration à distance
  53/TCP et UDP        DNS, résolution de noms
  67 et 68/UDP         DHCPv4, attribution d’adresses sur le réseau
  80/TCP               HTTP
  443/TCP              HTTPS sur TCP
  443/UDP              HTTP/3 sur QUIC, selon la configuration du serveur
  445/TCP              SMB, partage de fichiers Windows
  3306/TCP             MySQL
  3389/TCP et UDP      Bureau à distance Windows
  5353/UDP             mDNS, résolution de noms sur le réseau local
  5432/TCP             PostgreSQL
  6379/TCP             Redis

Le numéro donne un indice. Pour identifier l’usage sur ton PC, regarde le
processus, son exécutable et les services indiqués après sélection.
Registre IANA — https://www.iana.org/assignments/service-names-port-numbers
Référence HTTP/3 (RFC 9114) — https://www.rfc-editor.org/rfc/rfc9114.html

Les actions dans OpenPort

• Terminer le processus arrête le programme et toutes ses connexions.
  Windows libère les ports qu’il détenait.
• Bloquer le port dans Actions du port ajoute une règle du Pare-feu Windows pour
  le numéro et le protocole choisis. Windows demande les droits
  administrateur pour cette modification.
• Retirer le blocage supprime la règle créée par OpenPort. Si le port ne
  figure plus dans la liste, saisis son numéro dans le filtre, clique sur
  Retirer le blocage et choisis TCP ou UDP.
• Le clic droit sur une ligne donne accès aux mêmes actions. « Terminer
  et bloquer » arrête le processus après confirmation du blocage par Windows.
• « Durée (min) » s'applique aux actions temporaires. Windows programme le
  retrait de la règle de blocage, même si OpenPort quitte. Si le PC est
  arrêté à l'échéance, le Planificateur de tâches reprend le retrait après
  le redémarrage. Les autres règles de pare-feu continuent de s'appliquer.
• La surveillance des relances arrête les nouvelles instances du même
  exécutable au relevé suivant. Sélectionne une durée ou « jusqu'à Quitter ».
  Le menu « Relances » permet de réautoriser chaque application surveillée.

Règles du Pare-feu Windows — https://learn.microsoft.com/fr-fr/windows/security/operating-system-security/network-security/windows-firewall/rules

Surveiller et trier

Clique sur un en-tête pour trier, puis une seconde fois pour inverser le
tri. La flèche indique le sens. La liste démarre avec les ports à risque
en haut. Le menu des niveaux filtre cette liste et peut se combiner avec
la recherche. Le menu « Relevé » règle la cadence de 250 ms à 10 s,
avec 2 s par défaut. Les durées réelles varient selon le temps de collecte.

  À risque  Port habituel d'un service sensible, lié au réseau.
  Inconnu   Identité indisponible ou usage réseau à confirmer.
  Normal    Bouclage avec chemin identifié, processus système reconnu
            ou service Windows confirmé sur un port attendu.

Le détail affiche la raison du niveau. Ce classement décrit des indices
d'identité et d'exposition locale. Le pare-feu et la configuration du
réseau déterminent quels appareils peuvent effectivement se connecter.

« Vu depuis » mesure le temps depuis la première observation continue
dans cette session. Le détail affiche aussi l'âge du processus si
Windows le communique. Le compteur de surveillance démarre à l'ouverture.

Le graphique affiche les débits reçus et envoyés sur les 60 dernières
secondes à partir des compteurs d'octets Windows. Il additionne les
interfaces actives hors bouclage et interfaces de filtrage. Avec un VPN,
un paquet peut être mesuré sur plusieurs interfaces. Un débit à zéro
correspond à un intervalle mesuré. Un intervalle indisponible laisse un
trou dans le graphique. Les débits sont globaux. Le détail UDP indique
que l'activité par port est indisponible.

Survole une mesure sur le graphique pour lire ses débits et la durée de
l'intervalle. La croix masque la fenêtre. Un clic sur l'icône OpenPort près
de l'horloge rouvre la fenêtre. Son menu donne aussi accès à « Quitter ».
